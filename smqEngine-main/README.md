# smqEngine

# build
1. unzip

2.1. run: **clear; cargo run -p smq_game** to run the game

2.2. run: **clear; cargo run -p smq_editor** to run the editor

# info
this game engine uses rust and wgpu and bevy_ecs

the demo has deffered renderer with RT shadows (and it's not that slow 8k on my rtx 3050 ti i get ~16fps it's not bad)

you can do whatever you want with the graphics but you'l need to use wgpu functions directly
